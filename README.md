# Pouzin Society V2

Static Hugo rebuild of the public `pouzinsociety.org` website.

## Local development

```bash
npm run dev
```

## Re-import content from live site

```bash
npm run import
```

## Production build

```bash
npm run build
```

## Notes

- Content imported from the public legacy WordPress site
- Large legacy videos stay on the remote host to avoid bloating the repo
- GitHub Pages deployment runs through GitHub Actions
